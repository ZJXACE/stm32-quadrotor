## 今天的目标

让飞控板"不断电"、让四个电机能转起来，并把 FreeRTOS 真正跑起来。

## 今天做了什么

1. **CubeMX 加外设**
   - PB2 → `POWER_KEY`（推挽输出，初始高电平），用来周期性给 IP5305T 一个脉冲，防止移动电源芯片自动关机
   - TIM1/2/3/4 四个定时器各开一路 PWM，对应四个电机：
     | 电机 | 引脚 | 定时器/通道 |
     | --- | --- | --- |
     | RIGHT_0 | PA1 | TIM2_CH2 |
     | RIGHT_1 | PA10 | TIM1_CH3 |
     | LEFT_0 | PB4 | TIM3_CH1 |
     | LEFT_1 | PB9 | TIM4_CH4 |
   - 打开 `HAL_TIM_MODULE_ENABLED`
2. **工程分层**：新建 `MDK-ARM/Application`（应用层）、`MDK-ARM/Interface`（硬件接口层），`MDK-ARM/Common`（公共层）继续放调试打印
3. **FreeRTOS 启动**
   - `FreeRTOSConfig.h`：`configTOTAL_HEAP_SIZE` 改成 12KB；打开 `INCLUDE_xTaskGetSchedulerState`
   - 用宏别名把 `xPortPendSVHandler` / `vPortSVCHandler` 直接映射成 `PendSV_Handler` / `SVC_Handler`
   - `SysTick_Handler` 里先判断调度器状态，再调 `xPortSysTickHandler()`
   - `main.c` 里 `App_Freertos_Start()` 创建两个任务并启动调度器
4. **电机驱动 `Int_Motor`**
   - `Motor_Struct` 打包「定时器句柄 + 通道 + 速度」
   - `Int_Motor_SetSpeed()` → `__HAL_TIM_SetCompare()` 改占空比
   - `Int_Motor_Start()` → `HAL_TIM_PWM_Start()` 开通道
5. **电源管理 `Int_IP5305T`**：`Int_IP5305T_Start()` 拉低 100ms 再拉高，由电源任务每 10s 调一次
6. **新建第二个工程 `P02_remote_hal`**：遥控器端，USART1 + FreeRTOS + 同样的电源保持任务（PB15）

## 今天的关键数字

- PWM 计数时钟：72MHz ÷ 4 = **18MHz**；ARR = 1000-1 → PWM 频率 **18kHz**，周期 **55.55μs**
- 初始比较值 Pulse = 200 → 上电占空比 **20%**
- tick：`configTICK_RATE_HZ = 1000` → 1 tick = **1ms**；电机任务 6 tick = **6ms**，电源任务 10000 tick = **10s**
