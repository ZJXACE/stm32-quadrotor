# 2026-11-21 · 从零建工程，第一次打通串口

## 今天的目标

用 STM32CubeMX 从零建一个能跑的工程，把串口打印跑通。

## 今天做了什么

1. 用 **STM32CubeMX 6.18.1** 新建工程 `P01_flight_hal`，芯片选 **STM32F103C8T6**
2. 按下面这个顺序做配置（**这个顺序以后每次新建工程都用得上**）：
   1. **SYS → Debug = Serial Wire**
      —— 不选就没有 SWD，芯片会"变砖"（第二次下载就烧不进去，得按住复位救）
   2. **RCC → HSE = Crystal/Ceramic Resonator**
      —— 打开外部 8 MHz 晶振，不用内部 RC
   3. **Clock Configuration → HCLK = 72 MHz**
      —— HSE 8 MHz × PLL 9 = 72 MHz（F103 的极限主频）
   4. **Project Manager → Toolchain = MDK-ARM V5.32**，
      勾选 *Generate peripheral initialization as a pair of .c/.h files*
      —— 这样 `gpio.c` / `usart.c` 会分开生成，以后好维护
   5. **GENERATE CODE** 生成工程
3. Keil 打开 `MDK-ARM/P01_flight_hal.uvprojx`，编译通过，生成 `P01_flight_hal.hex`
4. VS Code + Keil Assistant 接管编辑，在 `Core/Src/main.c` 的 `/* USER CODE BEGIN 2 */` 里加了一句发送：

```c
HAL_UART_Transmit(&huart2, (uint8_t *)"Hello World!\r\n", 13, 0xFFFF);
```

5. 串口助手（115200 8N1）看到 `Hello World!` → **发送链路通了**

## 今天搞清楚的知识点

- **调试口 must-have**：`SYS → Debug: Serial Wire` 是 CubeMX 必选项，不是可选项
- **时钟树**：F103 走 HSE(8M) → PLL ×9 → SYSCLK 72M；APB1 只能 36M（÷2），所以挂 APB1 的定时器/UART 要按 36M 算
- **HAL_UART_Transmit 是阻塞发送**：第三个参数是"字节数"，不是字符串长度算错就多发垃圾；`0xFFFF` 是超时时间（ms）
- **`/* USER CODE BEGIN/END */` 之间的代码**：CubeMX 重新生成时会保留，写在**外面**的会被冲掉
- **生成的文件分两类**：`Drivers/` 是 ST 官方库（别改），`Core/` 是自己要改的
