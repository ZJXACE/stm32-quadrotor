## 今天的目标

把四个 LED 从"能亮"做成一套能表达状态的指示灯。

## 今天做了什么

1. **CubeMX 加四路 LED 输出**（初始高电平，低电平点亮）
   | 名字 | 引脚 | 位置 |
   | --- | --- | --- |
   | LED1 / LEFT_TOP | PA12 | 左上 |
   | LED2 / RIGHT_TOP | PA11 | 右上 |
   | LED3 / RIGHT_BOTTOM | PB15 | 右下 |
   | LED4 / LEFT_BOTTOM | PB14 | 左下 |
2. **新增 `Interface/Int_Led.c/.h`**：`Led_Struct` 封装「端口 + 引脚」，提供 `Int_led_on / off / toggle` 三个接口
3. **新增 `Common/Com_config.h`**：集中定义两个状态枚举
   - `RemoteControl_Status`：连接 / 断开
   - `Plane_Status`：空闲 / 飞行 / 定高 / 错误
4. **`Int_Led_Task` 写成状态机**
   - 前两个灯：遥控已连接 → 常亮；未连接 → 熄灭
   - 后两个灯：按飞行状态切换灯效（空闲慢闪 500ms、飞行快闪 200ms、定高常亮、错误熄灭）
   - 统一 100ms 节拍，用 `Count` 取余做"软件分频"

## 设计上值得记住的三点

1. **灯是"对象"不是"引脚"**：`Led_Struct` 让函数只认"哪盏灯"，不关心它接在哪个引脚
2. **灯效是"状态"驱动的**：状态变了灯才变，而不是写一堆 `vTaskDelay` 硬等
3. **一个任务管四盏灯**：用统一节拍 + 取余分频，而不是为每盏灯建一个任务或延时节拍

## 遗留问题

- `remote_control_status` 目前写死为 `REMOTE_CONTROL_CONNECTED`（为了调试时能看到两个灯亮），等遥控链路做好要改成由通信任务写入
- `plane_state` 初值是 `Error`，所以上电后后两个灯是**熄灭**的（不是坏了）
- `if / else if` 链最后没有 `else` 兜底，状态值异常时灯效会"保持上一次"

### 3. SPI1 + Si24R1 驱动（20:00~20:53）

- CubeMX 加 SPI1：PA5=SCK / PA6=MISO / PA7=MOSI，主机、模式 0、9MHz、MSB 先发
- 引脚：**CSN = PA4**（`SPI1_NSS`）、**CE = PA8**（`SP_EN`，待确认）、**IRQ 未接**
- 新增 `Int_SI24R1.c/.h`：`CS_LOW/CS_HIGH/CE_LOW/CE_HIGH` 宏、SPI 原语、4 个寄存器读写、RX/TX 模式、收发函数
- 修掉两个关键问题：
  1. `RxPacket` 清标志漏了命令位 → 补成 `SI24R1_WRITE_REG + STATUS`
  2. `TxPacket` 原来 `while(IRQ==1)` 死等 → 改成轮询 `STATUS` 的 `TX_DS/MAX_RT`
