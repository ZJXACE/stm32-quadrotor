## 怎么写一篇

复制下面这个骨架，换成当天的日期即可：

```markdown
# YYYY-MM-DD · 一句话标题

## 今天做了什么（时间线）
## 今天真正学会的东西（每条一个知识点，讲清"为什么"）
## 学习感悟
## 踩坑记录（现象 / 原因 / 解决）
## 明天的计划
```

三条写作原则：

1. **踩坑必须写"原因"**，只写"改好了"等于没写
2. **感悟写"以前怎么想的、现在怎么想的"**，对比才看得见成长
3. **能贴代码就贴最小可复现的那几行**，不要贴整个文件
