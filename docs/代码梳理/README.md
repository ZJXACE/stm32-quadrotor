## 读代码的顺序（建议）

1. `Core/Src/main.c` —— 看 `main()` 里按什么顺序初始化
2. `MDK-ARM/Application/APP_freertos_task.c` —— 看建了哪些任务、周期多少
3. `MDK-ARM/Interface/Int_*.c` —— 看每个硬件模块怎么被驱动
4. `Core/Src/tim.c` / `gpio.c` / `usart.c` —— 需要参数细节时再翻（CubeMX 生成，一般不用手改）
5. `Core/Inc/FreeRTOSConfig.h` —— 怀疑调度/时间不对时看这里
